ambroll
=======

![Application icon](./data/icons/hicolor/scalable/apps/io.bassi.Amberol.svg)

Ambroll (stylized as ambroll) is a fork of Amberol that tries to keep the
unintrusiveness and simplicity of amberol while adding essential features that
didn't make the cut.

The ambroll project aspires to have the same values that the original project
had and add features that were seemingly rejected for no reason.

Just like Amberol, ambroll plays music, and nothing else.

The recommended way of installing ambroll is to build from source.

Why is it called "Ambroll"?
---------------------------

The name comes from Amberol and the word b-roll as in extra.
I originally also planned to name it Amberol B-sides but this seemed more
fitting
